第三步！必须关闭杀毒、下载不下来提示各种病毒看下面二、三、四。
   关闭杀毒和下载防护如下！如果有其他问题直接截图问豆包为什么下载不下来。
一、关闭 Windows Defender 实时保护（杀毒拦截）
1. Win+S 搜索：**Windows 安全中心**，打开
2. 点【病毒和威胁防护】→【管理设置】
3. 关闭：**实时保护、云提供的保护、自动提交样本**
4. 篡改保护：如果想组策略永久关闭，需要先把【篡改保护】关掉（临时关闭不用动）
> Win10 路径：设置 → 更新和安全 → Windows 安全中心
> Win11 路径：设置 → 隐私和安全性 → Windows 安全中心
二、关闭系统 SmartScreen（文件下载、运行拦截提示）
1. Windows 安全中心 →【应用和浏览器控制】
2. 点【基于信誉的保护设置】
3. 关闭这三项：
   - 检查应用和文件
   - SmartScreen for Microsoft Edge
   - 阻止潜在不需要的应用
三、Edge 浏览器内下载风险提示关闭
1. Edge 右上角三个点 → 设置
2. 隐私、搜索和服务 → 往下找到【安全性】
3. 关闭 **Microsoft Defender SmartScreen**
快捷直达：`edge://settings/privacy`
四、方案 A：临时放行单个文件（推荐，不用全局关）
1. 下载被拦截时，在下载记录点【保留】【仍然保留】
2. 或者把文件所在文件夹加入**排除项**：
病毒和威胁防护 → 管理设置 → 添加或删除排除项 → 添加文件夹，选中存放安装包的目录。
